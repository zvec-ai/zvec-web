This path starts in the terminal. You can connect an AI agent after confirming that the workspace search works.

## Before you begin

- Node.js 22 or newer
- macOS, Linux, or Windows
- A local folder containing code, Markdown, text, or structured data

## 1. Install the CLI

```bash
npm install -g @zvec/zvec-grep
zg version
```

The package installs the `zg` command globally. `zg version` should print the installed version.

## 2. Index a workspace

Open the folder you want to search and create its first index:

```bash
cd /path/to/your/workspace
zg index --embedding local/potion-code-16m-v2
```

Choose the first model by workspace type:

| Workspace | Start with |
| --- | --- |
| Source code | `local/potion-code-16m-v2` |
| English documents | `local/potion-retrieval-32m` |
| Multilingual documents | `local/potion-multilingual-128m` |

Local model files are downloaded on first use. Workspace files and generated vectors remain on your machine.

Check that the index is ready:

```bash
zg status
```

## 3. Run one useful search

Search by meaning when you do not know the exact wording or location:

```bash
zg query --human "where theme preferences are restored" --limit 5
```

The result should contain ranked excerpts with file paths and source locations. If the result is empty, confirm the workspace root and index state with `zg status`.

## 4. Know the other two routes

Use ranked lexical search when you know the important terms:

```bash
zg query --fts "theme preferences" -g "src/**"
```

Use managed ripgrep for an exact or exhaustive lookup. It does not require an index:

```bash
zg query --rg -F "loadTheme" src
```

The default positional query is hybrid search. Read [Choose a retrieval mode](../search/) before adding advanced flags.

## 5. Optional: connect an AI agent

Run the guided installer to detect supported agents:

```bash
zg install
```

Or configure a target explicitly:

```bash
zg install --target codex --yes
```

The installer adds the local MCP connection and search guidance, then starts the local server when possible. Restart the agent or open a new session afterward.

Verify the server:

```bash
zg server status --check-ready
```

The same installer supports `codex`, `claude`, `cursor`, `opencode`, and `all`. Continue with [Connect an AI agent](../agents/) to verify the integration.
