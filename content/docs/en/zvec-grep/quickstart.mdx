## Before You Begin

- Node.js 22 or newer
- macOS, Linux, or Windows
- A local folder containing code, Markdown, text, or structured data

## 1. Install

```bash
npm install -g @zvec/zvec-grep
zg version
```

## 2. Index a Workspace

Run the command from the workspace you want to search:

```bash
cd /path/to/your/workspace
zg index --embedding local/potion-code-16m-v2
zg status --check-ready
```

The example model is a compact starting point for source code. For documents or multilingual content, see [Embedding Models](../embedding-models/). Local workspace files and generated vectors remain on your machine.

## 3. Search

Search by meaning when you do not know the exact wording or location:

```bash
zg query --human "where theme preferences are restored" --limit 5
```

The result should contain ranked excerpts with file paths and source locations. If it is empty, confirm the workspace root and index state with `zg status`.
