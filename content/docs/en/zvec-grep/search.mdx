Zvec-Grep offers complementary routes behind one `zg <query>` command. Start with the route that matches what you know, then narrow the search space before increasing the result count.

## Choose a Route

| Your intent | Command | Behavior |
| --- | --- | --- |
| Discover by meaning or combine meaning with keywords | `zg "authentication flow"` | Hybrid ranked sample |
| Rank known terms by relevance | `zg --fts "AuthService"` | BM25-ranked sample |
| Search only by conceptual similarity | `zg --vector "where credentials are validated"` | Vector-ranked sample |
| Find every literal or regex occurrence | `zg --rg -n -F "AuthService" src` | Exhaustive unless bounded |

<Callout type="info" className="text-base">
  Use `--rg` for exact or exhaustive work. Use indexed retrieval when wording or location is unknown, or when the answer requires relationships across files.
</Callout>

The default positional query combines lexical and vector retrieval:

```bash
zg --preview detail "where are user preferences restored at startup" --limit 5
```

Positional words are joined into one query, even when separately quoted. To run separate queries, repeat `--hybrid`, `--fts`, or `--vector`:

```bash
zg --hybrid "connection pool" --hybrid "socket timeout"
```

When a question also contains exact anchors, fuse them into one ranked plan:

```bash
zg --hybrid "authentication flow" --fts "ForbiddenError" --fuse --limit 10
```

## Narrow the Workspace

```bash
zg "plugin lifecycle" -g "src/**" -g "!src/generated/**" -t ts
```

| Option | Use it to |
| --- | --- |
| `-g`, `--glob`, `--iglob` | Include or exclude paths |
| `-t`, `--type`, `-T`, `--type-not` | Filter file types |
| `--modified-after` / `--modified-before` | Filter by modification time |

## Control Results and Freshness

| Option | Effect |
| --- | --- |
| `--limit <n>` | Maximum results per query group |
| `--preview none\|short\|full\|detail` | Source previews; `detail` adds metadata, outlines, and file grouping |
| `--debug` / `--trace` | Query and per-hit diagnostics |
| `--refresh background\|wait\|off` | Index freshness policy |

Output defaults to `--preview short` in terminals, pipes, and redirected files. `full` includes all available content of each retrieved item; it does not fetch an entire file.

Indexed results report `fresh` or `possibly_stale`. Refresh defaults to `background` in server mode and `off` in direct mode; direct mode cannot refresh in the background. Use `--refresh wait` when changes must be indexed before searching.

## Improve Weak Results

1. Confirm the workspace root and index state with `zg --status`.
2. Restrict the query to relevant paths or file types.
3. Add one or two concrete anchors with `--fts`.
4. Switch to `--rg` when the target text is known.
5. Review [Supported Content](../supported-content/) and the selected [Embedding Models](../embedding-models/).

Run `zg --help search` for the installed version's complete flag reference. If results remain weak, follow [Troubleshooting](../troubleshooting/).
