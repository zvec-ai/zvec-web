## Language SDKs

All SDKs share one stable C API boundary — pick your language to see the install command and prebuilt platform coverage.

<Tabs items={['Python', 'Node.js', 'Go', 'Rust', 'Java', 'Dart / Flutter', 'C / C++']}>

<Tab value="Python">

```bash
pip install zvec
```

- **Prebuilt coverage**:
  - Linux x86_64 / ARM64 (supports both glibc and musl libc)
  - macOS x86_64 / ARM64
  - Windows x86_64 / ARM64
- **Requirements**: 64-bit Python 3.10–3.14; no Python 3.10 wheel for Windows ARM64
- **Repository**: [https://github.com/alibaba/zvec/tree/main/python](https://github.com/alibaba/zvec/tree/main/python)

</Tab>

## PQ and FastScan

PQ is a quantization option for HNSW and IVF, not a separate index type. In **v0.8.1**, both indexes support PQ4/PQ8 with optional OPQ for dense FP32 vectors and L2, IP, or COSINE metrics.

| Configuration | HNSW | IVF |
| --- | :-: | :-: |
| PQ4 / PQ8 | ✅ | ✅ |
| PQ4 / PQ8 with OPQ | ✅ | ✅ |
| PQ4 with FastScan (OPQ optional) | ❌ | ✅ |

**SDK support:** Python exposes HNSW/IVF PQ starting with **0.8.1**. **Node.js SDK 0.8.0** does not expose PQ configuration. An SDK's general support for HNSW/IVF does not imply that it exposes every quantizer option.

**Feature availability and SIMD acceleration are distinct.** FastScan is available only with IVF-PQ4. The [v0.8.1 kernel dispatcher](https://github.com/alibaba/zvec/blob/v0.8.1/src/turbo/turbo.cc#L705) selects an implementation based on CPU capabilities:

| CPU capabilities | FastScan execution path |
| --- | --- |
| x86_64 with AVX512F and AVX512BW | AVX-512 |
| x86_64 with AVX2 | AVX2 |
| ARM64 with NEON | NEON |
| No matching SIMD path | Scalar fallback |

The build must also include the relevant SIMD implementation. Missing a listed instruction set does not by itself make PQ or FastScan unavailable: the implementation provides a scalar fallback. This does not change the SDK, platform, or index constraints above, and does not imply equal performance across CPUs.

See [Product Quantization](../concepts/vector-index/quantization/product-quantization/) for configuration, training, and tuning.
