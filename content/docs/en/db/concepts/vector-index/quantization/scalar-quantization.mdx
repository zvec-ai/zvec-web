Scalar Quantization (SQ) reduces the precision of each vector dimension independently. FP16 uses a smaller floating-point representation, while INT8 and INT4 use integer quantization. Unlike [Product Quantization (PQ)](../product-quantization/), SQ encodes individual dimensions rather than groups of dimensions.

## Quantization Types

### FP16 (Half-Precision Floating Point)

Uses 16-bit floating-point numbers to reduce memory footprint and accelerate computation while maintaining high numerical precision. Ideal for applications requiring near-FP32 accuracy with improved efficiency. Requires conversion from FP32 source.

### INT8 (8-Bit Integer Quantization)

Represents vectors using 8-bit integers, significantly reducing storage and memory bandwidth requirements. Offers a good trade-off between speed, size, and retrieval accuracy for many similarity search tasks. Requires conversion from FP32 source.

### INT4 (4-Bit Integer Quantization)

Ultra-compact representation using only 4 bits per dimension. Maximizes storage density and inference speed, suitable for latency-sensitive or resource-constrained environments where noticeable accuracy loss is acceptable. Requires conversion from FP32 source.

## Enabling Quantization

Set `quantize_type` to `FP16`, `INT8`, or `INT4` in the index parameters passed to `VectorSchema.index_param`, such as `HnswIndexParam` or `IVFIndexParam`. SQ is the name of this quantization family; the API uses the individual type names.

See the [HNSW schema example](../../../../collections/create/schema/#hnsw-example) for an INT8 configuration. Zvec manages the quantized representation alongside the original vectors; see [Storage Behavior](../#storage-behavior) for the storage and memory trade-offs.

## Enabling Rotation

  <PythonLinkButton url="/api-reference/python/schema/#zvec.model.schema.VectorSchema" label="Python API Reference" />

When using `INT8` or `INT4` quantization, you can **set `enable_rotate=True` via the `quantizer_param` parameter in your index parameters** to enable rotation. This applies a random orthogonal rotation to vectors before quantization, making the distribution across dimensions more uniform, which reduces information loss during quantization and improves the recall of the quantized index. For PQ, this option enables learned [OPQ](../product-quantization/#enabling-rotation) instead.
