[**Collection**](../concepts/data-modeling/#collections) 是 Zvec 中用于存储 [Document](../concepts/data-modeling/#documents) 的命名容器。

可以将 Collection 类比为关系型数据库中的表：它是你*存储、组织和查询数据*的地方。
