你可以将**向量搜索**与**标量过滤器**结合使用，将结果限制在 Document 的子集中 — 就像为相似度搜索添加一个 `WHERE` 子句。

## 前提条件

本指南假设你：

- 已经打开了一个 `collection` 实例。
- 熟悉[向量查询](../single-vector/)和[条件过滤](../filter/)。

  ```ts tab="Node.js" title="打开一个 Collection"
  // [!code word:dense_embedding]
  // [!code word:publish_year]

      name: "example_collection",

          {
              name: "dense_embedding",
              dataType: ZVecDataType.VECTOR_FP32,
              dimension: 768,
              indexParams: { indexType: ZVecIndexType.HNSW, metricType: ZVecMetricType.COSINE }
          }
      ],
      fields: [
          {
              name: "publish_year",
              dataType: ZVecDataType.INT32,

      ]
  ```

  ```java tab="Java" title="打开一个 Collection"
  // [!code word:dense_embedding]
  // [!code word:publish_year]
  import org.zvec.binding.*;

  CollectionSchema collectionSchema = new CollectionSchema("example_collection");   // [!code highlight]

  try (FieldSchema denseEmbedding = new FieldSchema("dense_embedding", DataType.VECTOR_FP32, false, 768);
       IndexParams hnsw = IndexParams.createHNSW(MetricType.COSINE, 16, 200)) {
      denseEmbedding.setIndexParams(hnsw);
      collectionSchema.addField(denseEmbedding);
  }

  try (FieldSchema publishYear = new FieldSchema("publish_year", DataType.INT32, true, 0);

      collectionSchema.addField(publishYear);
  }

  Collection collection = Zvec.open("/path/to/collection", null);   // [!code highlight]
  ```

## 执行向量过滤搜索

要将向量相似度搜索与过滤器结合，请同时将[查询规范](../#query)和 `filter` 表达式传递给 `query()` 方法。

```python tab="Python" title="向量过滤相似度搜索" tab-group="code-demo"
import zvec

result = collection.query(
    queries=zvec.Query(  # [!code highlight]
        field_name="dense_embedding",
        vector=[0.1] * 768,  # 请替换为真实的 Embedding
    ),
    filter="publish_year > 1936",  # 仅考虑 1936 年之后出版的书籍   [!code highlight]
    topk=10,
)
print(result)
```

```ts tab="Node.js" title="向量过滤相似度搜索"
let result = collection.querySync({   // [!code highlight]
    fieldName: "dense_embedding",
    vector: Array(768).fill(0.1),   // 请替换为真实的 Embedding
    filter: "publish_year > 1936",  // 仅考虑 1936 年之后出版的书籍 [!code highlight]
    topk: 10
});
console.log(result);
```

```java tab="Java" title="向量过滤相似度搜索"
import java.util.Arrays;
import java.util.List;
import org.zvec.binding.*;

float[] vector = new float[768];
Arrays.fill(vector, 0.1f);   // 请替换为真实的 Embedding

try (VectorQuery query = new VectorQuery()) {   // [!code highlight]
    query.setFieldName("dense_embedding");
    query.setQueryVector(vector);
    // 仅考虑 1936 年之后出版的书籍
    query.setFilter("publish_year > 1936");   // [!code highlight]
    query.setTopK(10);

    List<Doc> result = collection.query(query);
    for (Doc doc : result) {
        System.out.println(doc.toDetailString());
    }
    Doc.freeDocs(result);
}
```

这将返回满足 `publish_year > 1936` 条件的前 10 个最相似 Document，按相似度评分排序。
