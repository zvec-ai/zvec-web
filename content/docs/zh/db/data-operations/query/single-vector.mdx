单向量搜索用于查找与单个查询 Embedding 最相似的 Document。这是向量数据库中最常见的搜索模式。

---

## 前提条件

本指南假设你已经打开了一个 Collection，并准备好了一个 `collection` 对象。

<Accordions type="single">
  <Accordion title="示例 Collection 设置">

  此示例 Collection 包含两个向量字段：

  1. **`dense_embedding`** — 768 维稠密向量，使用余弦距离
  1. **`sparse_embedding`** — 稀疏向量，使用内积距离

  它还包含两个标量字段（`publish_year` 和 `category`）。

  ```python tab="Python" title="打开一个 Collection" tab-group="code-demo"
  import zvec

  # [!code word:dense_embedding]
  # [!code word:sparse_embedding]
  collection_schema = zvec.CollectionSchema(  # [!code highlight]
      name="example_collection",
      vectors=[
          zvec.VectorSchema(
              name="dense_embedding",
              data_type=zvec.DataType.VECTOR_FP32,
              dimension=768,
              index_param=zvec.HnswIndexParam(metric_type=zvec.MetricType.COSINE),
          ),
          zvec.VectorSchema(
              name="sparse_embedding",
              data_type=zvec.DataType.SPARSE_VECTOR_FP32,
              index_param=zvec.HnswIndexParam(metric_type=zvec.MetricType.IP),
          ),
      ],
      fields=[
          zvec.FieldSchema(name="publish_year", data_type=zvec.DataType.INT64),
          zvec.FieldSchema(name="category", data_type=zvec.DataType.ARRAY_STRING),
      ],
  )

  collection = zvec.open(path="/path/to/collection")  # [!code highlight]
  ```

  ```ts tab="Node.js" title="打开一个 Collection"
          {

              name: "category",
  ```

  ```java tab="Java" title="打开一个 Collection"

  // [!code word:sparse_embedding]

  try (FieldSchema denseEmbedding = new FieldSchema("dense_embedding", DataType.VECTOR_FP32, false, 768);
       IndexParams hnsw = IndexParams.createHNSW(MetricType.COSINE, 16, 200)) {
      denseEmbedding.setIndexParams(hnsw);
      collectionSchema.addField(denseEmbedding);

      collectionSchema.addField(sparseEmbedding);

  try (FieldSchema publishYear = new FieldSchema("publish_year", DataType.INT64, true, 0)) {
      collectionSchema.addField(publishYear);
  }

  try (FieldSchema category = new FieldSchema("category", DataType.ARRAY_STRING, true, 0)) {
      collectionSchema.addField(category);
  }

  Collection collection = Zvec.open("/path/to/collection", null);   // [!code highlight]
  ```

## 执行单向量搜索

要执行单向量相似度搜索，请使用 `query()` 方法并提供一个[查询规范](../#query)。

<Accordions type="multiple">

<Accordion title="稠密向量搜索示例">

```python tab="Python" title="使用单个向量查询" tab-group="code-demo"
import zvec

result = collection.query(  # [!code highlight]
    queries=zvec.Query(
        field_name="dense_embedding",
        # 稠密 Embedding 是浮点数列表
        vector=[0.1] * 768,  # 实际使用时请替换为真实的 Embedding
    ),
    topk=3,
    include_vector=False,  # 不返回向量 Embedding
)
print(result)
```

```ts tab="Node.js" title="使用单个向量查询"
// 同步版本
let result = collection.querySync({   // [!code highlight]
    fieldName: "dense_embedding",
    // 稠密 Embedding 是浮点数数组
    vector: Array(768).fill(0.1), // 实际使用时请替换为真实的 Embedding
    topk: 3,
    includeVector: false  // 不返回向量 Embedding
});
console.log(result);

// 异步版本
let resultAsync = await collection.query({   // [!code highlight]
    fieldName: "dense_embedding",
    // 稠密 Embedding 是浮点数数组
    vector: Array(768).fill(0.1), // 实际使用时请替换为真实的 Embedding
    topk: 3,
    includeVector: false  // 不返回向量 Embedding
});
console.log(resultAsync);
```

```java tab="Java" title="使用单个向量查询"
import java.util.Arrays;
import java.util.List;
import org.zvec.binding.*;

// 稠密 Embedding 是浮点数数组
// 实际使用时请替换为真实的 Embedding
float[] vector = new float[768];
Arrays.fill(vector, 0.1f);

try (VectorQuery query = new VectorQuery()) {   // [!code highlight]
    query.setFieldName("dense_embedding");
    query.setQueryVector(vector);
    query.setTopK(3);
    // 不返回向量 Embedding
    query.setIncludeVector(false);

    List<Doc> result = collection.query(query);
    for (Doc doc : result) {
        System.out.println(doc.toDetailString());
    }
    Doc.freeDocs(result);
}
```

<Callout className="text-base" type="warn">
  **Java 暂不支持**：`VectorQuery.setQueryVector()` 只接受稠密的 `float[]`，而 `MultiQuery` 要求至少 2 个子查询，因此无法在 Java 中表达单个稀疏向量查询。把稠密数组传给稀疏字段并不会报错，只会让每个结果的分数都静默变成 `-0.0`，所以不要用这种方式绕过限制。要在 Java 中检索稀疏字段，请在 `MultiQuery` 中将它与至少一个其他子查询组合，并用 `SubQuery.setSparseVector(int[], float[])` 设置向量；参见[多向量搜索](../multi-vector/)。
</Callout>

<Accordion title="按 ID 查询示例">

```python tab="Python" title="使用单个向量查询"
import zvec

result = collection.query(  # [!code highlight]
    queries=zvec.Query(
        field_name="dense_embedding",
        id="book_1",  # 使用该 ID 对应 Document 的 'dense_embedding'
    ),
    topk=100,
    include_vector=True,  # 返回向量 Embedding
    output_fields=["publish_year"],  # 返回 'publish_year' 字段
)
print(result)
```

```java tab="Java" title="使用单个向量查询"
import java.util.Collections;
import java.util.List;
import org.zvec.binding.*;

// `VectorQuery` has no query-by-id option, so fetch the seed document first
// and reuse its embedding. `fetch()` always returns vector fields.
List<Doc> seedDocs = collection.fetch(Collections.singletonList("book_1"));   // [!code highlight]
float[] queryVector = seedDocs.get(0).getVectorFP32Field("dense_embedding");
Doc.freeDocs(seedDocs);

try (VectorQuery query = new VectorQuery()) {   // [!code highlight]
    query.setFieldName("dense_embedding");
    query.setQueryVector(queryVector);
    query.setTopK(100);
    query.setIncludeVector(true);   // Returns the vector embedding
    query.setOutputFields(new String[]{"publish_year"});   // Returns the 'publish_year' field

    List<Doc> result = collection.query(query);
    for (Doc doc : result) {
        System.out.println(doc.toDetailString());
    }
    Doc.freeDocs(result);
}
```

<Callout className="text-base" type="info">
  **Java**：`VectorQuery` 没有按 `id` 查询的选项，因此上面的示例先用 `collection.fetch()` 取出种子 Document，再把它的 Embedding 传给 `setQueryVector()`。`fetch()` 始终返回向量字段，无需额外配置。
</Callout>

<Callout className="text-base" type="info">

  所有查询都返回一个 `list[Doc]`，包含 **top-k** 个最相似的 Document，按相关性评分排序。

  每个 `Doc` 对象包括：

  1. `id`：Document 标识符。
  1. `score`：相似度评分。
  1. `vectors`：向量字段名称到对应 Embedding 值的映射。  
      仅在查询中传入 `include_vector=True` 时才会填充。
  1. `fields`：标量字段名称到存储值的映射。  
      默认返回**所有标量字段**；可通过 `output_fields` 参数限制返回的字段。

  Java 中查询返回 `List<Doc>`。可通过 `getPK()`、`getScore()`、`getVectorFP32Field(name)` 以及 `getStringField(name)` 等类型化 getter 读取相同的值，也可以用 `toDetailString()` 一次性打印整个 Document；读取完成后使用 `Doc.freeDocs()` 释放结果。

</Callout>

## 参数

执行向量搜索时，`query()` 方法接受两类参数：

1. **通用参数**，无论底层索引类型如何都适用
1. **索引特定参数**，允许根据使用的向量索引微调搜索行为

### 通用参数

下表参数名使用 Python 写法；Node.js 使用驼峰写法（`includeVector`、`outputFields`），Java 使用对应的 `VectorQuery` setter（`setTopK()`、`setIncludeVector()`、`setOutputFields()`、`setFilter()`）。

| 参数 | 描述 |
| --------- | ----------- |
| `topk` | 返回最相似 Document 的数量。 |
| `include_vector` | 如果为 `True`，返回的 `Doc` 对象包含完整的向量 Embedding（默认禁用以提升性能）。 |
| `output_fields` | 可选的标量字段名称列表，用于指定结果中包含的字段。如果省略，返回所有标量字段。 |
| `filter` | 可选的类 SQL 布尔表达式，用于限制结果。详见[过滤搜索](../filter/)。 |

<Callout className="text-base" type="warn">
  `reranker` 参数是 `query()` 接口的一部分，但**仅适用于[多向量搜索](../multi-vector/)**。  
  请勿在单向量查询中提供该参数。
</Callout>

### 索引特定参数

你可以随查询一起传递索引特定的查询参数来微调搜索行为：Python 使用 `Query` 对象的 `param` 选项，Node.js 使用 `params`，Java 使用对应的 `VectorQuery` setter（`setHNSWParams()`、`setIVFParams()`、`setIvfRabitqParams()`、`setDiskAnnParams()` 等）。

这些 `param` 的确切类型和结构取决于目标向量 Embedding 所使用的向量索引。如果省略，将使用默认值。

<Accordion title="HNSW 索引示例" id="hnsw-example">

如果 `dense_embedding` 使用 [HNSW](../../../concepts/vector-index/hnsw-index/) 索引，你可以像这样调整 `ef` 参数：

```python tab="Python" title="使用索引特定参数查询" tab-group="code-demo"
result = collection.query(    # [!code highlight]
```

```ts tab="Node.js" title="使用索引特定参数查询"
let result = collection.querySync({   // [!code highlight]

    topk: 10
});
console.log(result);
```

