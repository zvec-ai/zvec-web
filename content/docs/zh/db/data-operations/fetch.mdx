使用 `fetch()` 按 `id` 获取 [Document](../../concepts/data-modeling/#documents)。
这是一个**直接查找**操作——不涉及搜索、评分或过滤。

```python tab="Python" title="获取 Document" tab-group="code-demo"
# [!code word:fetch]
# 获取单个 Document
result = collection.fetch(ids="book_1")
print(result)   # { "book_1": Doc(...) }


# 获取多个 Document
result = collection.fetch(ids=["book_1", "book_2", "book_3"])
print(result)   # { "book_1": Doc(...), "book_2": Doc(...), "book_3": Doc(...) }
```

```ts tab="Node.js" title="获取 Document"
// [!code word:fetchSync]
// 获取单个 Document
let result = collection.fetchSync("book_1");
console.log(result);    // { "book_1": {...} }

// 获取多个 Document
let results = collection.fetchSync(["book_1", "book_2", "book_3"]);
console.log(results);   // { "book_1": {...}, "book_2": {...}, "book_3": {...} }
```

```java tab="Java" title="获取 Document"
import java.util.Arrays;
import java.util.Collections;
import java.util.List;
import org.zvec.binding.*;

// [!code word:fetch]
// 获取单个 Document
List<Doc> result = collection.fetch(Collections.singletonList("book_1"));
System.out.println(result.get(0).toDetailString());
Doc.freeDocs(result);

// 获取多个 Document
List<Doc> results = collection.fetch(Arrays.asList("book_1", "book_2", "book_3"));
for (Doc doc : results) {
    System.out.println(doc.toDetailString());
}
Doc.freeDocs(results);
```

- **输入**：单个 Document `id` 或 `id` 列表。
- **输出**：从每个**找到的** `id` 到对应 Document 对象的映射。Java binding 返回的是 `List<Doc>`，可通过 `getPK()` 读取每个 Document 的 `id`。
- 不存在的 `id` 会被**静默忽略**（不会抛出错误）。
- 返回结果不保证输入顺序——请通过 `id` 访问 Document。
