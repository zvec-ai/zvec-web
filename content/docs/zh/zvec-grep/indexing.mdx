索引检索提供 BM25、向量与混合检索。精确的 `--rg` 检索无需索引即可使用。

索引大型工作区前，请先确认[支持的内容](../supported-content/)与 [Embedding 模型](../embedding-models/)。

## 创建第一个索引

在工作区根目录运行：

```bash
zg index --embedding local/potion-code-16m-v2
zg --status --check-ready
```

索引保存在 `<workspace>/.zvec-grep/` 下，后续扫描会自动排除该目录。

## 限定首次构建范围

大型工作区应在第一次构建时选择相关路径：

```bash
zg index \
  --embedding local/potion-code-16m-v2 \
  -g "src/**" \
  -g "docs/**" \
  -g "!dist/**"
```

## 保持索引更新

已有索引会复用模型与文件选择设置：

```bash
# 增量更新
zg index

# 查看索引覆盖率与配置
zg --status
```

`zg --status` 只显示四个字段：`Coverage`、`Embedding`、`FTS` 和 `Storage`。
`Coverage` 包含文件计数；索引未就绪时会附加简短状态说明。统计信息不可用时，显示 `Unavailable` 和当前状态。
脚本中使用 `zg --status --check-ready`：输出保持不变，索引未就绪时返回非零退出码。

更换模型需要显式重建：

```bash
zg index --rebuild --embedding local/jina-embeddings-v2-base-code
```

只有确实需要替换已有包含与排除规则时，才使用 `--reset-paths`。

## 删除索引

删除索引是显式且具有破坏性的操作：

```bash
zg index --drop --yes
```
