Zvec-Grep 在同一个 `zg query` 命令下提供多条互补的检索路径。先选择与你掌握的信息最匹配、最简单的一条。

## 选择检索路径

| 你的意图 | 命令 | 结果特点 |
| --- | --- | --- |
| 按语义发现，或同时使用语义与关键词 | `zg query "认证流程"` | 混合检索后的排序样本 |
| 按相关性排列已知关键词 | `zg query --fts "AuthService"` | BM25 排序样本 |
| 只按概念相似度检索 | `zg query --vector "凭证在哪里校验"` | 向量排序样本 |
| 找到所有文本或正则匹配 | `zg query --rg -n -F "AuthService" src` | 默认穷举匹配 |

<Callout type="info" className="text-base">
  精确或穷举任务使用 `--rg`。措辞或位置未知，或者需要跨文件理解关系时，使用索引检索。
</Callout>

## 从混合检索开始

最短的命令会联合词法与向量检索：

```bash
zg query --human "用户偏好在启动时从哪里恢复" --limit 5
```

`--human` 会展示更完整的终端预览。不添加时，输出会保持紧凑，更适合脚本与 Agent 上下文。

## 合并多组线索

问题同时包含宽泛概念和精确标识符时，可以融合多个查询组：

```bash
zg query \
  --hybrid "authentication flow" \
  --fts "ForbiddenError" \
  --fuse \
  --limit 10
```

不添加 `--fuse` 时，各查询组会分别返回结果。

## 一条实用的路由规则

1. 精确定位已经足够时，使用 `--rg`。
2. 措辞或位置未知时，使用默认混合查询。
3. 明确关键词需要影响排序时，增加 `--fts`。
4. 只有明确需要纯语义检索时，才使用 `--vector`。
